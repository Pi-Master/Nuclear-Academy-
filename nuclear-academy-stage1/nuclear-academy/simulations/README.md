# Simulations

One folder per simulation (`simulations/<id>/sim.js` plus an optional `README.md`), described by a file following `content/_templates/simulation.template.json`. The planned list per school is in `docs/CURRICULUM.md`. Stage 1 creates no simulations; the existing atom explorer still lives in `index.html`.

Rules: educational and conceptual only, every simulation states its principle and model limits, no operational reactor tools, no weapons-related content, no external services.
